🎓 Gerar Dataset de Treino

Sobe várias fotos → cada uma é analisada pela Sonnet (já calibrada) → o resultado vira uma linha de treino (foto + resposta correta) → no final você baixa o arquivo .jsonl pronto para fine-tuning.

⚠️ Cada foto processada aqui chama a API da Sonnet de verdade — tem custo real (~R$0,01–0,03 por foto), mas NÃO conta no limite de análises de nenhum usuário. Use fotos variadas (doenças, deficiências, pragas, frutos, folha saudável) para o dataset ficar equilibrado.
📷 Toque para escolher várias fotos de uma vez
